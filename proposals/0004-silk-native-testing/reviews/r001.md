## Contract

### Thesis

Silk should provide a minimal, general-purpose native testing architecture: compiler-known test
declaration discovery and opaque invocation are exposed through sealed primitives, while ordinary
Silk owns the customizable runner, replaceable reporting, minimal assertions, filtering, and
aggregate policy.

### In-scope claims

- **C1 — Authoring and inventory.** `test` is a marker on eligible private, top-level, named,
  non-generic, zero-parameter unit functions. A test compilation exposes every marked declaration
  in its rooted module closure in canonical-module then source order, with stable fully qualified
  identities.
- **C2 — Minimal compiler boundary.** Sealed primitives expose an ordered inventory of opaque
  `Test.Function` handles, identity metadata, and invocation without creating ordinary erased
  callable values or recognizing standard-library declarations by spelling.
- **C3 — Invocation and isolation.** `Test.run` invokes one handle under the runner's lexical
  environment and fresh per-case Reporter/Effect scope. Normal return passes; any escaping typed
  failure becomes `Failed { path }` with the existing logical failure path; traps remain fatal.
  Application services must be provided inside the test.
- **C4 — Reporting and assertions.** A replaceable mutable `Test.Reporter` receives structured
  assertion events before `Test.Failure` escapes. `Test.assert(bool)` and non-generic
  `Test.equalBytes(&[u8], &[u8])` are ordinary standard-library source and retain no compared values.
- **C5 — Runner ownership.** The selected runner is ordinary Silk and owns test selection,
  invocation order, presentation, and aggregate policy. The test command passes it raw borrowed
  filter strings through a narrow runner-entry adapter; the compiler does not filter the inventory.
- **C6 — Standard runner policy.** The default runner applies case-sensitive substring filters to
  fully qualified IDs, ORs multiple filters, preserves canonical order, and returns `0` for all
  selected tests passing, `1` for any selected typed failure, and `2` when explicit filters match
  nothing.
- **C7 — Initial execution boundary.** `silk test` runs once through the evaluator on the ordinary
  host target. Native/Wasm test execution and target matrices have no initial contract.
- **C8 — General usefulness.** The architecture is equally available to user projects and the
  standard library; the existing seeded Random scalar and `fillBytes` programs are sufficient
  pressure cases for the minimal first version.

### Out of scope

- Generic equality, automatic structural comparison, diagnostic value rendering, retained
  expected/actual values, assertion messages, or exact assertion-callsite tracking.
- Skipping, tags, glob/regular-expression/exclusion filters, shuffling, retries, parallelism,
  process isolation, snapshots, fuzzing, coverage, or watch mode.
- Source-visible target/build configuration, target-conditioned declarations, compiled native or
  Wasm test modes, target matrices, or recoverable trap isolation.
- Rendering arbitrary application failure payloads or allowing arbitrary residual application
  service requirements on test declarations.
- Final intrinsic names, handle/frame representation, custom-runner project configuration, exact
  terminal formatting, OpenSpec decomposition, implementation tasks, or implementation code.

## Blockers

- S1 — Reporter-only eligibility contradicted the no-library-spelling privilege boundary.
- S2 — the test-root set was undefined.
- S3 — invocation promised freshness that caller-controlled lexical provision cannot enforce.
- P3 — the test-specific parameter-bearing entry duplicated existing HostInput capability.
- E2 — the ordinary-source API examples used unsupported enum declarations.

## Revision response

- S1: revised the inventory/invocation primitive to accept a source-supplied service-type witness;
  `silk.test` supplies Reporter, and no compiler phase recognizes its spelling.
- S2: defined user `[test].roots`, fallback to `package.root`, and a deterministic standard-library
  test-root catalog; test compilation unions and de-duplicates the resulting closures.
- S3: restricted fresh Reporter and Effect scope to standard-runner policy; custom runners retain
  ordinary lexical provider control and may share reporter state.
- P3: restored the zero-parameter runner and routes raw filter arguments through existing
  `silk.host_input`.
- E2: replaced enum examples with current structs and structural unions; the runner and custom
  reporter examples were repaired for affine ownership at the same boundary.

Not stopped — verified blockers were revised in Candidate revision 32.
