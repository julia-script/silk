## Goals / Non-Goals

Deliver JUL-181 with no providers, heap allocation, compiler privilege, transcript retention, or protocol state. Other cryptographic primitives retain separate owners.

## Decisions

Expose TlsHkdfSha256 and TlsHkdfSha384, with expandLabel, deriveSecret and deriveSecretFromHash. Secrets and transcript hashes have fixed array widths. LabelError distinguishes LabelLength, ContextLength, OutputLength and MessageTooLong; only public length bounds appear in errors.

Validate label/context/output before any narrowing, writes, or empty-output return. Frame into a fixed 514-byte local array and pass only the initialized prefix to generic HKDF. Reuse generic HKDF errors as the matching OutputLength boundary. Message derivation checks SHA-256's byte domain before hashing and then delegates to from-hash derivation. SHA-384's domain exceeds every addressable slice on selected targets.

Public lengths determine framing work, hash work and HKDF block count. Secret bytes do not select wrapper branches or addresses. This does not establish constant-time generated code, erase copied secrets, or supply TLS trust.

## Verification

Commit RFC 8448 SHA-256 intermediates and SHA-384 outputs generated by the pinned Zig oracle, with reproduction evidence. One shared native corpus program covers distinct framing, derivation and rejection claims. Structured analysis covers wrong hash widths and borrow overlap; a small LLVM-to-Wasm witness checks intended portability. Inspect emitted optimized target output and obtain independent correctness/security and test-economics review.

## Risks / Trade-offs

Fixed framing storage is bounded but is not secure memory. Full-profile admission remains blocked on other primitive and protocol deliveries. Verification records the exact work-base and branch commands; concurrent measurements are not comparable.
