## ADDED Requirements

### Requirement: Dependent storage facts participate in reusable semantic summaries

Variance, outlives and cleanup facts SHALL participate in exported semantic dependency validation. Changed facts invalidate actual consumers; implementation edits preserving those facts do not force unrelated body checks. Generic bodies and canonical type-pair comparisons remain reusable and lifetime arguments introduce no runtime instance or layout dimension. Opt-in measurements SHALL distinguish constraints, loan regions, recursive summaries, residual ownership and failed diagnostic construction without enumerating state combinations.

#### Scenario: Lifetime-only instantiations share representation

- **WHEN** an unchanged generic wrapper is instantiated with distinct borrow regions
- **THEN** semantic obligations are checked while runtime layout and instance identity remain shared
