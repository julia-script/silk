embedded programs, generated import templates, and selected-member aliases. The requested dotted
pattern was checked separately; its non-import matches are TypeScript assertions or ordinary prose.

No import aliases remain in `packages/compiler/stdlib/silk/` or `compiler/src/`.
Primitive imports retain lowercase module names. Nonprimitive public functions have inherent owners;
root constants and supporting enums use selective imports because impls contain operations.

The remaining aliases below are deliberate language/tooling test inputs or reference explanations.
They do not establish an alias convention for ordinary programs. Malformed alias fixtures are also
retained to exercise parser recovery. Native exported-symbol `as` clauses and type-alias declarations
are separate language features and were not rewritten as imports.
